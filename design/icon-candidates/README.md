# アイコン案（Nano Banana Pro生成・2026-08-17）

韓国国旗（太極旗）と朝鮮半島の形を参考に5案作成。サイト全体が白基調なので、白地の案を中心にした。

| 案 | 内容 | 16pxでの読みやすさ |
| --- | --- | --- |
| C1 | 太極（赤×紺の円）＋細い紺のリング ← **暫定採用** | ◎（赤紺の渦は最小サイズでも韓国と分かる。NZ=A2・AU=B2と同じ円形でシリーズが揃う） |
| C2 | 白地＋赤の細いリング＋紺の韓国 | △（リングが細く軽い） |
| C3 | 紺の角丸＋白い半島 | ○ |
| C4 | 太極と半島を斜めに配置 | ×（要素が小さく潰れる） |
| C5 | 白地＋赤のスタンプ枠＋紺の半島 | △ |

⚠️ 生成画像の背景は透明ではない（白や模様が描かれている）。faviconにする前に
   **円の外側を透明に抜いてトリミング**する（NZのA2・AUのB2でも同じ手当てをした）。
⚠️ ico は必ず RGBA で保存する。RGBだと Next のビルドが落ちる。
⚠️ C3・C5は北朝鮮を含む半島全体の形。韓国旅行の案内という用途を踏まえると、
   地図を使わないC1が誤解の余地が無く安全。
